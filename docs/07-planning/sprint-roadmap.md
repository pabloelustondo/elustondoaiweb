# Elustondo.ai Sprint Roadmap

**Status:** Rolling planning baseline; roadmap entries are not implementation authorization
**Last updated:** 2026-08-01

## Current sequence

| Sprint | Goal | Principal boundary | Expected human-visible result |
|---|---|---|---|
| 001 — Real Website Foundation | Build the first real static website foundation and homepage. | `StableShell` and repository build/test foundation | Running responsive homepage with official branding, tests, screens, browser logs, and server logs |
| 002 — Public Content | Add the complete public corporate and knowledge pages. | Static content model and permanent routes | Navigable Articles, Projects, Methods, People, About, and Contact experience |
| 003 — Deterministic Assistant Experience | Add the AI-assisted interface with fixed safe fixtures. | `AssistantPanel`, `SiteNavigator`, and `GeneratedPageCanvas` | Predictable navigation, generated-page, clarification, refusal, and failure demonstrations |
| 004 — Assistant Safety Pipeline | Add the versioned endpoint and containment controls using a deterministic adapter. | `AssistantEndpoint`, `IntentRouter`, `OutputGuard`, route/source allow-lists | End-to-end controlled pipeline with negative security and contract tests |
| 005 — Controlled Live AI and Firebase Preview | Connect an approved provider and deploy a bounded preview. | `ModelAdapter`, managed secrets, operational controls, Firebase preview | Real provider experiment with safety, latency, cost, and operational evidence |
| 006 — Release Hardening | Complete public-release QA and rollback readiness. | Cross-cutting release candidate | Reviewed Firebase candidate ready for Pablo's release decision |

## Roadmap rules

- Only the exact approved Sprint Plan and immutable implementation prompt activate work.
- The next sprint is reconsidered after the current sprint's evidence and deferrals are known.
- Any unresolved official-brand or reviewed-content dependency may block the affected acceptance criterion.
- Voice, authentication, protected customer applications, persistent conversation history, and source-aware open-web research remain outside these six sprints.
- DNS cutover is a release action after the approved candidate, not a sprint side effect.
