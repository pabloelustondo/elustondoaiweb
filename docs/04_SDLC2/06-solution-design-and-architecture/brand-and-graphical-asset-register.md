## 1. Purpose

This register defines the canonical Elustondo.ai brand files, their intended applications, and the separation between official identity assets, website-specific graphics, publication graphics, working files, and archived experiments.

The objective is to prevent repeated logo redesign, accidental use of obsolete candidates, inconsistent colours, duplicated masters, and AI-generated approximations.

## 2. Governing rule

Only files explicitly listed as canonical in this register may be used as official Elustondo.ai identity assets.

Do not:
- redraw the shield;
- recreate the stars or wordmark;
- alter colours;
- stretch or compress the logo;
- change internal spacing;
- substitute an AI-generated approximation;
- publish a file marked Candidate, Draft, Experiment, or Archived;
- create a new official variant without an explicit brand decision.

## 8. Website and publication graphics

Folder: 05 Website & Publication Graphics

This folder contains finished non-logo visuals used on the website, in articles, or in public technical communication, including:
- article cover images;
- project diagrams approved for publication;
- social-preview images;
- technical-methodology posters;
- screenshots prepared for public display;
- section graphics;
- exported Open Graph images.

Every item should record or make clear:
- title and purpose;
- source/creator;
- creation date;
- intended channel;
- copyright/permission status;
- whether it is final or working;
- alt text when used on the web.

Do not place official logo masters in this folder.

## 9. Website-specific asset boundary

Website-only working and delivery assets belong under:
C7-Corporation / Elustondo.ai Website / 05 Website-Specific Assets

That project folder contains mockups, page-specific imagery, team photographs, responsive evidence, social-preview exports, favicon build outputs, working files, and archived website iterations.

The website must reference or copy approved build-time versions of canonical logos from Brand & Marketing. It must not become a competing brand source of truth.

## 10. Archive policy

Folder: 99 Archive — Superseded & Experiments

Move obsolete candidates, previous alignments, generated experiments, rejected frames, and replaced logo versions here instead of deleting them.

Archived files should be renamed when necessary to make their status explicit, for example:
ARCHIVED-Elustondo.ai-Logo-Long-2026-07-26.png
EXPERIMENT-Elustondo.ai-Header-Blue-Gradient.png
SUPERSEDED-Elustondo.ai-PayPal-Pre-Centering.png

Archive contents must never be used in production without a new explicit approval decision.

## 11. File format policy

SVG
Preferred master format for logos, icons, diagrams, and scalable applications. Preserve vector source.

PNG
Use for transparent raster fallbacks, email systems, previews, and platforms without SVG support.

WebP or AVIF
Use for optimized website photography and complex raster illustrations when browser support and quality are validated. Retain an original source file.

PDF
Use for controlled documents or print-ready distribution, not as the primary website image format.

## 13. Website usage matrix

Website header
Use Elustondo.ai-Logo-Primary.svg.

Favicon/browser icon
Use Elustondo.ai-Icon-Square.svg and generated standard favicon sizes from the approved icon master.

About/legal corporate identification
Use Elustondo.ai-Logo-Corporate.svg or textual corporate name, depending on layout.

Article cards
Use approved article-specific graphics; do not use the corporate logo as a generic thumbnail.

Article endings
Use Elustondo.ai-Article-Signature.png when a signature is appropriate.

Contact/footer
Use text or the primary/corporate lockup sparingly; avoid repeating several logo forms on one page.

Email
Use Elustondo.ai-Email-Signature-Mark.png.

Payments
Use only the approved payment assets in 02 Payment Assets.

## 14. Quality checks before publication

- Correct canonical source file selected.
- No Candidate/Draft/Archive file used.
- Aspect ratio preserved.
- Background compatibility verified.
- Sufficient size and sharpness.
- File optimized without visible degradation.
- Accessible alt text defined for meaningful web images.
- Copyright and consent confirmed.
- No confidential information visible.
- Final placement reviewed on desktop and mobile.
