## 1. Canonical identity source

Official logos, icons, signatures, payment applications, and brand guidance are maintained under:

The website project must consume those files without creating alternative masters.

## 2. Website-specific asset structure

00 Website Asset Index
This index and future asset manifests.

01 Design References & Mockups
Approved mockups, wireframes, design explorations, and design-review exports.

02 Page & Section Graphics
Finished hero visuals, article-card graphics, project images, diagrams, and page illustrations.

03 Team Photos
Approved original portraits and optimized web exports. Generated portraits are prohibited.

04 Social Preview & Favicons
Open Graph images, social preview cards, favicon exports, browser icons, and platform-specific sizes generated from canonical masters.

05 Generated & Working Files
Temporary exports, editable working files, generated alternatives under review, and non-canonical intermediate material.

99 Archive
Superseded mockups, rejected experiments, previous exports, and retired page graphics. Archived material is not production-approved.

## 3. Asset lifecycle

Working → Reviewed → Approved → Optimized export → Added to repository → QA evidence → Production.

Every final asset should record:
- filename;
- purpose;
- source/creator;
- date;
- page/section;
- copyright or consent status;
- approved alt text;
- original dimensions;
- optimized web format;
- approval state.

## 4. Naming convention

Elustondo.ai-[Page]-[Subject]-[Purpose]-[Variant]-[Dimensions].[ext]

Examples:
Elustondo.ai-Home-Hero-TechnicalPattern-Desktop-1600.webp
Elustondo.ai-Articles-SDLC2-Card-800.webp
Elustondo.ai-OpenGraph-Default-1200x630.png

Working-state prefixes:
DRAFT-
EXPERIMENT-
SUPERSEDED-
ARCHIVED-

## 5. Production rule

A graphic is production-ready only when:
- the source and rights are known;
- the content is accurate and public-safe;
- the official logo is used correctly;
- dimensions and compression are appropriate;
- desktop and mobile placement are reviewed;
- alt text is defined where needed;
- the file is referenced from the GitHub repository;
- the Firebase preview passes QA.

## 6. Current baseline

The July 2026 editorial homepage rendering is a design reference, not a final production screenshot. It must be rebuilt using the official logo files and reviewed content. Approximate SVG logos, generated portraits, sample roles, and placeholder links from exploratory renderings are not canonical assets.
